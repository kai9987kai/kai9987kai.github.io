      Quick Form: describe fields, get a laid-out UI
      
        
      
      
      
      
        
        
      
          Syntax
          
      # Title sets the window title and heading.
      
          ## Section starts a titled group (LabelFrame).
      
          Label or Label: type adds a field. Add * for required and = default for an initial value.
      
          --- adds a separator.
      
          [Save] [Cancel] adds a right-aligned button row.
      
          Types
          
      text (default), email, password, multiline, number(0, 120), choice(A, B, C), radio(A, B), check, switch, slider(0, 100), list(A, B, C), progress, date, table(Col1, Col2).
      
          
      Every input gets a visible label, fields are aligned to a grid and created in reading order, so the result passes the audit's labelling and focus-order checks out of the box. Labels go on top by default: in Penzo's (2006) eye-tracking study, top-aligned labels were the fastest to complete.
