Built as a single-file web app. Data sources: UniProt, STRING, Reactome, AlphaFold DB, InterPro, PDBe/SIFTS and EMBL-EBI protein variation services.
If you hit CORS issues when opening as file://, run a local server: python -m http.server 8000 then open http://localhost:8000/.
