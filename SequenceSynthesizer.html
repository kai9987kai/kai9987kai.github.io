Compatibility & usage notes

This is a deterministic, prompt-conditioned procedural art synthesizer, not a text-to-image ML service. All styles and original PNG/JPEG/GIF/SVG/audio capabilities remain. Vector export approximates raster effects; GIF uses a fixed 256-colour palette. Projects work offline as a single HTML file. The browser's local file policy may restrict sharing links and storage.
