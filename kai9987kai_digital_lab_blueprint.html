This project now proves software maintenance, regression testing, packaging and security hygiene—not only automation.

tests passing

Up from 20, with GUI, classic window, lite app and built executable also verified manually.

import-time improvement

Correctness + product

The v11 work fixed a 2–3× timing error caused by PyAutoGUI pauses, added precise pacing, pause/resume, hotkeys, scheduled starts, history, new actions and a real argparse CLI with 14 subcommands.

Production front door

  • One valid HTML document and one application bootstrap.
  • No arbitrary top-level script execution.
  • No visitor-IP cookie or unsolicited permission prompts.
  • Fast project cards, case studies, 3D previews and measured performance.

  • Web Plugins sandbox.
  • Web Bluetooth / pen-pressure experiments.

90-day execution roadmap

Turn breadth into evidence without a giant rewrite.
  1. Freeze the legacy homepage as an archive snapshot. Stop adding experiments to the production root.
  2. Ship a minimal new root homepage. Hero, five capability areas, six flagships, 3D strip, contact.
  3. Write three deep case studies. Supermix, AutoClicker modernisation and one scientific/3D interactive system.
  4. Create /lab. Move experimental browser APIs, device panels and Web Plugins into labelled sandboxes.
  5. Make Supermix the AI flagship. Show architecture, local-first constraints, benchmark method, routing and packaging.
  6. Make NEXUS the “how I work” demo. Use it to show product thinking and information architecture.
  7. Rebuild 3D visibility. Surface modelling, technical-art and Three.js work as a first-class track.
  8. Add proof to every project. Problem → constraints → implementation → result → limitations → next iteration.
  9. Remove privacy/performance hazards. IP tracking, worker storms, duplicate handlers/libraries and automatic permission requests.
  10. Measure the new site. Lighthouse, bundle size, accessibility, interaction latency and mobile layout.
