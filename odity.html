    Training & environment

    Scientific interpretation

    Both systems have the same neuron count, initial weights, inputs, noise and readout width. The grafted network can have additional internal states and compute: this is not a strict capacity or FLOP-matched contest. Scores are pre-update predictions, not training accuracy.

    Inspect update equations

    x′ = tanh(0.62x + 0.58Wa + 0.70us + 0.35y + 0.24z + 0.22f + 0.19m + ε) × g
    y′ = tanh(0.86y + 0.24x + 0.27Wa)
    z′ = 0.91z + 0.09 Σ W sin(φ) a
    m′ = 0.94m + 0.06a
    f = Wᵀa
    a = 0.70x + 0.30y [dual] + 0.15m [memory], clipped.
    p = σ(b + vᵀa); v ← v + η(t − p)a.
    Each optional module contributes only when enabled. During frozen evaluation all learning is off.

    ODDITY LAB is an exploratory artificial recurrent dynamical system, not a validated neuroscience model, an AGI, or evidence of consciousness. Log-loss and accuracy can disagree. Evaluating multiple configurations on the same test seeds can itself overfit the benchmark; replicate with new held-out seeds. The exported configuration hash is an ordinary FNV-1a checksum for reproducibility, not a cryptographic integrity proof.
