⟡

Multi-soma state integration

Four coupled state channels: fast membrane-like response, slow integration, neighbour context and persistent trace. Their outputs are fused before readout.

⌘

Structural representation

Compact connectivity fingerprints include in/out degree, weighted strength, reciprocity, local motifs and two-hop reachability. A contextual weighting proxy uses neighbouring states.

✳

Sparse distributed coding

Global k-winners selection retains the strongest candidate activations. Sparsity is adjustable; the baseline has this mechanism disabled.

◌

Associative trace memory

Reward-qualified input/state snapshots are kept in a bounded local episode store. Similar input keys can retrieve a weak activation trace.

↯

Reward-gated plasticity

Eligibility traces accumulate pre/post activity. A scalar outcome signal gates bounded synaptic updates; Dale-style source signs are preserved in this prototype.

▦

Hardware-inspired execution

Connection updates are grouped into tiles, with double-buffered state arrays and operation/byte estimates. This is a software execution model, not an FPGA bitstream.

∆

Local predictive coding

Each unit maintains a local estimate, prediction error and surprise trace. Bounded residuals modulate state fusion without changing the eight-channel readout contract.

↗

Spike-timing-dependent plasticity

Pair-based timing traces support local weight adaptation while preserving excitatory/inhibitory source signs.

⇄

Adaptive synaptic routing

Destination-compartment context adjusts bounded transmission gains, independently of static graph structure.

◷

Hierarchical temporal memory

Fast, medium and slow traces preserve distinct decay timescales inside every synthetic unit.

◇

Uncertainty-gated propagation

Ensemble disagreement scales recurrent transmission. It is a heuristic, not calibrated Bayesian confidence.

◉

Ten-region multimodal connectome

Visual, auditory, olfactory, gustatory, thermal, mechanosensory, interoceptive, association, memory and motor populations connect through local clusters and explicit long-range routes.

⌁

Multimodal sensory cortex

Sixteen bounded input channels combine webcam luminance, colour, edge and motion features, audio bands, simulated chemical/taste/thermal/touch signals and agent interoception.

✳

Neuromodulatory affect state

Reward valence, arousal, curiosity, stress and motivation proxies interact with separate transmitter fields and heterogeneous receptor sensitivities. These are control variables, not felt emotions.

▦

Micro-Collective sparse experts

A compact four-expert top-2 predictor learns sensor transitions online, balances expert use, prioritises novelty and keeps held-out validation with rollback.

↻

Safe continual learning

Bounded replay, a separate validation stream, best-state snapshots and learning-rate reduction protect the small model from runaway online updates.

Reproducibility / 04

Research notes & boundaries

NEUROWEAVE is a testbed for falsifiable computational hypotheses, not a biological brain simulation or an intelligence claim.

Read before interpreting

What this project combines

  • WireType-inspired: representing a unit using its connectivity context and neighbouring-unit information.
  • Fly-Distill-inspired: controlled topology comparisons, recurrent dynamics and hub-concentration experiments.
  • Fly-Protein-inspired: sparse coding, bounded associative memory and reward-gated adaptation.
  • FPGA-accelerator-inspired: tiled operations, buffering, quantisation research hooks and execution-cost accounting.
  • Sonapse-LAB-inspired: recurrent connectome substrate, homeostatic regulation, structural plasticity and multi-stage measurement.
  • ODDITY-LAB-inspired: matched baseline/candidate runs, independent ablations, prequential scoring, seed replication and exports.

What it does not claim

  • It does not load or reproduce the real FlyWire / hemibrain connectome.
  • It does not include ESM-2, protein datasets, a transformer, or protein-fitness prediction.
  • It does not produce FPGA hardware, measure electrical power, or demonstrate the published accelerator speedup.
  • Its multi-soma compartments, synaptic plasticity and structural features are mathematical abstractions, not validated models of biological neurons.
  • It does not establish consciousness, sentience, general intelligence or biological plausibility.

Recommended experimental protocol

  1. Record the baseline with all candidate mechanisms disabled.
  2. Enable one mechanism at a time; rebuild both conditions from the same seed.
  3. Use identical stimulus sequences, task schedules and evaluation windows.
  4. Score predictions before updating readout weights or synapses.
  5. Run multiple independent seeds and retain per-seed results.
  6. Compare accuracy, log-loss, latency, memory and operation estimates together.
  7. Keep a feature only when gains survive stronger controls and do not introduce regressions.

Data handling

All simulation data is generated in the browser. Microphone input is optional and processed locally as an amplitude feature; raw audio is not recorded, saved or transmitted by this application. JSON and CSV exports are created only when you press the export button. Browser microphone access generally requires localhost or HTTPS.
