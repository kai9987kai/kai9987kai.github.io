Mathematical specification

A fixed-weight, non-spiking surrogate for an unusually shaped synthetic neuron. The hidden representation has N states; dual-soma variants partition those states into two groups of N/2.

pₜ₊₁ = tanh(ρₚ pₜ + Wₚ hₜ + Uₚ xₜ + bₚ)
mₜ₊₁ = tanh(ρₘ mₜ + Wₘ hₜ + Uₘ xₜ + bₘ + γ · gₜ ⊙ rₜ)
rₜ = tanh(A(pₜ, mₜ, xₜ))
gₜ = sigmoid(G(pₜ, mₜ, xₜ))
hₜ = concat(pₜ, mₜ)  →  ŷ = sign(wᵀ hᵀ + b)

Point baseline uses homogeneous decay (ρ = 0.82); dual variants use primary ρₚ = 0.62 and secondary ρₘ = 0.96. Full DSAG gates the axonal term; ungated ablation sets g = 1; dual ablation sets γ = 0. Only the final readout is trained, using ridge regression (λ = 0.35), so this tests reservoir expressivity—not end-to-end plasticity.

Interpretation guardrail: Matching the number of states and trained readout weights does not match the architectures' fixed connections or compute. A positive result motivates harder tests against parameter-, compute- and tuning-matched baselines, including GRUs/LSTMs. Negative or unstable results are scientifically useful.

Reproducibility & promotion gate

Nothing is uploaded or sent anywhere. All simulations and audit exports run locally. This standalone prototype does not modify Sonapse-LAB or replace any existing neuron, graft, dataset or pipeline.

✓

Deterministic streams
Seeded generator for synthetic episodes and model weights; held-out episodes and matched seeds for all four architectures.

✓

Frozen protocol
Fixed ridge penalty, fixed architecture equations, and unchanged testing procedure across ablations.

✓

Stress generalisation
OOD evaluation adds 3 extra cue-separation steps and 0.15 Gaussian noise to held-out episodes; no retraining.

→

Promotion gate
Do not integrate a winning DSAG variant until replicated across ≥10 seeds and multiple tasks, with complexity-matched controls, memory-forgetting evaluation, and regression tests on existing Sonapse capabilities.
